# KC-1957 左 Ctrl 与 Fn 完全互换改造 —— v7（P0.6 去抖）

本目录为 v7 版本产物。v7 = v6 + **P0.6 去抖**。

> ⚠️ **使用前必读**
>
> 1. **硬件版本**：本补丁只适用于 **V2 及以上**硬件。V1 等低版本固件布局不同，注入地址与键位表假设不成立，**不要尝试**；低版本设备需自行向持有 V2+ 固件的人索取一份 V2+ 固件。
> 2. **不要用哈希校验固件**：每台设备 Dump 出来的固件本来就不完全一样（蓝牙名称、2.4G 无线 ID 等为设备独有），原厂固件与补丁产物的 SHA-256 **都因机而异**。正确判据是**补丁脚本的前置检查**（干跑）与**验证脚本的结构性检查**。
> 3. **`--out` 必须显式指定**：不指定时会回退到输入路径，配合 `--apply` 会**覆盖你的原始固件**。

## 文件清单

| 文件 | 说明 |
|---|---|
| `KC-1957_88_orig.bin` | 原始固件（512 KB，MCU nRF52832） |

| `verify_v7.py` | 独立验证脚本（89 项检查） |
| `thumbsim.py` | 最小 Thumb 解释器（供验证脚本做行为仿真） |
| `KC-1957_左Ctrl与Fn互换改造说明_P06去抖_v7.md` | 说明文档（单一事实源） |
| `KC-1957_左Ctrl与Fn互换改造说明_执行原理_v7.html` | 执行原理（框图模式） |
| `SHA256SUMS.txt` | 文件校验和 |

## 用法

```text
# 干跑检查
python fn_swap_debounce_patch.py KC-1957_88_orig.bin

# 写出补丁固件
python fn_swap_debounce_patch.py KC-1957_88_orig.bin --out KC-1957_88_v7.bin --apply

# 独立验证
python verify_v7.py KC-1957_88_orig.bin KC-1957_88_v7.bin
```

## v7 相对 v6 的变化

P0.6 发 Left Ctrl 的判定由「原始 P0.IN bit6」改为「去抖后的 E0F2」，消除机械按键抖动导致的 Left Ctrl 误触发。差异仅 trampoline C（0x50200 区）与 trampoline E（0x50400 区）共 50 字节。

详见 `KC-1957_左Ctrl与Fn互换改造说明_P06去抖_v7.md`。
